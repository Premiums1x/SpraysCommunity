综合课程设计

**题目：基于 Spring Boot 3 的校园流浪动物图鉴与动态打卡系统设计与实现**

**1.** **课程设计目的**

本课程设计是计算机科学与技术/软件工程专业集中实践性教学环节。通过本课题的设计，要求学生：

（1）深入理解并掌握 Spring Boot 3.x 核心框架的设计思想与依赖注入机制。

（2）熟练运用 JDK 17/21 新特性、MyBatis-Plus（或 Spring Data JPA）持久层框架及 MySQL 数据库进行规范化开发。

（3）掌握基于 RESTful API 规范的后端接口设计方法、文件上传以及标准分层架构（Controller-Service-Mapper）。

（4）培养独立分析业务需求、设计关系型数据库表结构、解决多表关联查询及工程代码调优的实际动手能力。

**2.** **系统角色与权限定义**

系统主要面向校园内的两类用户群体：

普通学生/教工（User）：主要负责浏览全校流浪动物信息，并在偶遇小动物时在线发布最新的近况打卡动态。

系统管理员（Admin）：负责全校流浪动物电子档案的建立、更新与日常维护。

**3.** **系统核心功能模块与业务规范**

系统核心围绕“动物档案”与“日常打卡”展开，重点考核一对多（One-to-Many）的关系型业务构建。

3.1 校园动物图鉴管理模块（管理员端）

档案录入：管理员可录入新发现的流浪动物信息，字段包括：暂定名字、动物类型（猫/狗）、常驻区域（如：图书馆草坪、西区食堂）。同时需支持本地文件上传，为动物上传第一张封面照片。

档案检索：要求支持按动物名字模糊查询、按类型（猫/狗）进行条件筛选，并支持分页返回。

档案删除（Delete）：支持对误填或无效的动物档案进行删除。

 

3.2 偶遇近况打卡模块（用户端）

**即时打卡发布**：学生在校园内偶遇某只小动物时，可选择该动物的 ID，在线编写一段文字描述（如：“今天在教学楼下看到它了，喂了根猫条，精神状态良好”），发布后直接生成一条动态记录。

**动态时间轴查询**：用户点击某只动物的详情页时，后端需根据动物 ID 关联查询打卡动态表，按时间倒序（最新发布的在最前）聚合返回该动物的历史足迹列表，在前端/接口端呈现为“时间轴近况”。
